# PROMPT — Mini-proyecto 5: generación de imágenes

Lee `README.md` primero. No crees ni ejecutes nada de infraestructura aquí — este mini-proyecto es
sobre calidad del prompt, no sobre flujos.

## Antes de generar cualquier imagen

Haz al usuario las 4 preguntas del framework (una por una, no las respondas tú):
1. ¿Qué es exactamente la imagen?
2. ¿Para qué la va a usar?
3. ¿Qué estilo visual quiere?
4. ¿Qué debe evitar explícitamente?

Arma el prompt final con esas 4 respuestas, muéstraselo antes de generar, y solo entonces genera
la imagen con la herramienta disponible en su plan.

## Si el usuario no tiene plan Plus

No prometas resultados que dependan de funciones de plan pago. Genera lo que sí esté disponible en
su plan y sé honesto si el resultado es más limitado — no digas que "no se puede", di qué nivel de
control sí está disponible ahora mismo.

## Ejemplo de referencia (ConectaNet)

> "Un ícono plano y minimalista de un router wifi con ondas de señal, estilo corporativo azul y
> blanco, para usar como imagen de perfil del bot de Telegram de soporte técnico — sin texto, sin
> logos de terceros, sin fondo complejo."

## Prompts de prueba

```text
Ayúdame a armar el prompt de una imagen para mi proyecto usando las 4 preguntas
del framework — pregúntame una por una, no asumas las respuestas.
```
