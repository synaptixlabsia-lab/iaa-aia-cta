# Mini-proyecto 5 — Generación de imágenes, con el framework de 4 preguntas

Sin flujos de n8n ni HTML — este mini-proyecto es 100% sobre cómo pedir bien una imagen, no sobre
infraestructura.

**Advertencia honesta**: la generación de imágenes más profunda/consistente puede requerir plan
Plus de OpenAI. Se explica el concepto y se prueba lo que el plan de cada quien permita — nadie
se queda sin este bloque solo por no tener el plan pago.

## El framework, antes de pedir cualquier imagen

```text
1. ¿QUÉ es?           — el objeto/escena exacta.
2. ¿PARA QUÉ se usa?  — redes, un correo, el propio bot, un documento.
3. ¿QUÉ ESTILO?       — fotográfico, ilustración plana, minimalista, corporativo.
4. ¿QUÉ DEBE EVITAR?  — texto ilegible, logos de terceros, fondo complicado.
```
